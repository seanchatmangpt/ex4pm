## Standing

Missing external multi-region evidence remains `PARTIAL_ALIVE`; `BLOCKED`, `BUILD_BROKEN`, or `REFUSED` evidence dominates. No manual override exists.

The detached final crown remains an artifact about an exact source commit/tree; it is not committed into the Git tree it certifies.
